# BUS445-Cell2Cell-Project
BUS 445 Team Project: Cell2Cell retention analysis for Raj Patel (Director of Retention Operations).

## Setup
1. Download the Canvas data file (and the dataset description) into `data/raw/` (git-ignored, never commit it).
   The cleaning script expects `data/raw/cell2celltrain.csv`; change `RAW_FILE` at the top of the script if yours is named differently.
2. Open `BUS445-Cell2Cell-Project.Rproj` in RStudio so the working directory is the repo root.
3. Run `R/01_clean.R` once (needs `dplyr` and `readr`).

## Using the clean data
Start every analysis script with:

```r
cc <- readRDS("data/clean/cell2cell_clean.rds")
train <- subset(cc, split == "train")
test  <- subset(cc, split == "test")
```

Everyone uses the same split (seed 445, 70/30, stratified by churn).

## Shared variables (`R/01_clean.R`, section C3)
| Lever / role | Variables |
|---|---|
| Handset | `handset_age_months`, `handset_age_band`, `handset_web`, `handset_refurb`, `handset_price` (about 57% unknown) |
| Plan fit | `overage_share` (OverageMinutes / MonthlyMinutes), `overage_band`, `revenue_gap` (MonthlyRevenue - TotalRecurringCharge) |
| Network | `drops_per_min`, `blocked_per_min` (and per-100-minute versions), `drops_band`, `blocked_band`. `DroppedBlockedCalls` is not used |
| Service (descriptive only) | `care_call_flag` (reverse causation risk) |
| Controls | `MonthsInService`, `tenure_band`, `credit_rating`, `multiline_flag`, `usage_decline_flag`, `zero_usage_flag` |
| Save-desk (stability refit only, never in the lever ranking) | `retention_calls`, `retention_offers_accepted`, `made_retention_call` |
| Dollars / pilot | `MonthlyRevenue`, `ServiceArea` |

Per-minute rates are `NA` for customers with zero minutes; use `zero_usage_flag` for them.

## Outputs (`output/`, regenerated by the script)
- `data_issues.csv`: problems found in the raw file
- `cleaning_steps.csv`: rows dropped at each step and why
- `lever_distributions.csv`: distributions and missing values (EDA check E2)
- `churn_by_band.csv`: churn rate by band for each lever
- `file_discrepancies.csv`: where the file differs from the dataset description (for the memo's data section)
